## 产品定位

Dotty Tutor 是一个本地优先的学习项目，验证“教材/错题输入 → 结构化互动内容 → 学生作答 → 错题陪练 →
掌握验证 → 复习”的学习闭环。当前只聚焦中文教材和初中数学，不追求一次覆盖所有学段和商业化场景。

## 当前版本：MVP

已具备：

- 内容生产端可以上传教材、识别题目、生成互动试卷并经过结构质量门禁后发布。
- 学生端可以消费已发布试卷，完成选择、判断、填空、数值、简答和画线等题型。
- 错题可以进入陪练线程，获得分层提示、变式验证和掌握度记录。
- 支持错题本、进阶本和 1/3/7 天复习任务的本地演示闭环。

## P0：稳定当前演示闭环

完成标准：学生可以连续完成一套题；内容生产者可以得到可展示的题目；失败时有明确反馈，不会无限等待。

- [x] 学生提交正确答案后稳定进入下一道未完成题；最后一道题进入完成态，也可以回看已完成题目。
- [x] 已提交题目保留答案和结果，刷新或返回后按钮显示“重新提交”。
- [x] 错题陪练完成态能够进入验证；验证只需要一道题，答错可以重新提交。
- [x] 学生做题时不主动请求 TTS 或讲解，只有主动求助时才产生反馈。
- [x] 错题归档不删除作答和学习证据；归档会清理旧陪练线程和消息，恢复后重新创建线程。
- [x] 题干、选项、条件、讲解和历史消息中的公式、图片、Markdown 图片保持一致显示，并有内容生产端与学生端 Playwright 回归覆盖。
- [x] 内容生产端支持单题修复和整套重新审核，并清楚显示实际生成/审核模型、运行 ID 与修订号。
- [x] 生成、审核、陪练和 OCR 模型选择相互独立，学生端不暴露内容生产配置。

本轮已完成：内容生产端的单题修订版本、批次重生成、重新 OCR 和整套重新审核均返回不可变审计证据；OpenAPI 类型生成与校验已接入。

## P1：强化学习闭环

- [ ] 将错题原因与变式策略、提示层级和验证题难度稳定关联。
- [ ] 完善掌握度证据、进阶本迁移和 1/3/7 天复习任务的可解释展示。
- [ ] 增加错题复习完成率、验证正确率和同知识点再次出错等学习反馈。
- [ ] 支持移动端和弱网环境下的作答恢复、上传取消和学习记录同步。
- [ ] 对典型学生路径补充 Playwright 回归测试和可重复演示数据。

## P2：内容表现和学习实验

只有 P0/P1 稳定后再做：

- [ ] 交互数学实验题（函数、坐标、几何构造）。
- [ ] 知识动画、视频讲解和答题反馈动效。
- [ ] 已审核教材片段的轻量检索辅助讲解。
- [ ] TTS 缓存、离线预生成和更多课程内容块。

## 明确暂缓

- A Level 多学科题库。
- 商业化会员、支付、多租户、班级和教师运营后台。
- 7×24 SLA、高可用、弹性扩缩容和完整公网运营体系。
- Multi-Agent、LangChain、LangGraph 等全局代理编排。

## 产品验收原则

1. 先验证学生是否能完成任务，再增加模型或页面能力。
2. 任何 AI 功能都必须有确定性状态机、错误回退和可重复测试。
3. 新题型、新动画或新模型必须是独立实验，不阻塞现有错题和复习闭环。
