# 教材与课程统一入口验收

2026-10-03：首页只保留“打开我的教材”，`/studio` 在同一列表展示已上传教材、数学课程和英语阅读。旧 `/studio/chapters` 列表地址跳转到此处；课程详情和学生链接仍可访问。

## 原问题与改动

1. 用户需要先理解两种制作流程才能选入口。现在先进入“我的教材”，再上传文件、粘贴原文或继续制作已有内容。
2. 创建课程同时显示版本、来源标记和区域坐标。现在默认填写名称、学科、原文或教材页、来源许可，高级来源设置按需展开。从教材卡片进入时自动带入文件和名称，默认选一页。
3. 工作台同时堆放制作方式、来源修订、发布历史。现在按“生成草稿 → 复核内容 → 发布课程”提示当前步骤，其余操作折叠。评分要点按普通文字逐行编辑，保留原有审核状态，不要求用户编辑 JSON。

真实本地页面已只读检查：五条现有教材记录仍显示，选取教材后课程表单正确带入文件和名称。没有上传、迁移或删除用户材料，也没有创建真实课程或调用模型生成。当前数据库没有英语课程；入口合并不会自动把验收目录中的英语 PDF 导入应用。
