## 本机门禁

已独立执行真实 PostgreSQL 的复核/公共保护/题号专项 51 条通过。
随后完整后端 `bash scripts/test-backend-postgres.sh` 最终运行 791 条、全部通过，覆盖率 75%；
`uv run ruff check .`、`uv run pyright`、测试纪律、确定性 replay 均通过。
最终前端 `pnpm lint`、`pnpm vitest run`（41 文件/158 条）、`pnpm check:api`、
`pnpm exec tsc --noEmit`、`pnpm run build` 全部通过；独立端口 E2E 23 条通过。
E2E 使用 API 夹具，新增复核写入和匿名评分由 DOM 与真实 PostgreSQL 契约分别覆盖，不能将其写成真实浏览器全链路写入验收。
过程中首轮全量后端实际执行 772 条，4 条失败：新增渲染器 preflight 的两处旧断言、
旧中文教材 replay 的题号回归、未受管素材临时摘录的契约场景。这些失败及随后页码测试文本、模型目录有效候选夹具不匹配已修正；最后冻结状态 790 条通过。
兼容迁移新增旧0021缺列且存在真实历史数据的升级回归，随后全量790条通过。远端 CodeQL 发现新增 OpenStax 标题正则的空白回溯风险，Luna 将四组规则改为行内空白与占有量词；新增异常空白后保留109题的回归，最终全量791条通过。根代理另对50万字符的单行制表符、多行空白和无效 TRY IT 执行12组解析探针，均无误匹配，耗时约1.2～2.7毫秒；静态告警是否清除以当前PR的CodeQL为准。原页和Docker健康已实测，最终页码文案、窄屏换行和模型目录生成能力边界均完成；真实目录排除 embedding-only 模型，390px页面无横向溢出（scrollWidth375）。

Docker 实际镜像的 FFmpeg 为 `7.1.5-0+deb13u1`，构建包含 `--enable-gpl --enable-libx264`；
CairoSVG 为 2.9.1。FFmpeg/x264 的发行版权文件保留并实际检查存在。
