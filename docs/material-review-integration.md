# 教材复核融入现有工作台

日期：2026-10-11。基线：`38439974`；分支：`feature/integrate-material-review`。

## 目标与边界

用户从「我的教材」发现待审内容，进入具体章节的「复核内容」步骤，对照原页记录来源意见并继续课程审核。已有质量复核数据、来源修订、课程与媒体发布历史、匿名模型运行都保留。

来源案例的人工决定与课程、媒体的批准分别绑定其版本。接受来源案例不会自动批准课程、发布视频或修改学习掌握度。公开教材单审仍不能成为独立双审人工金标准。教材互动课件生成另见[课件计划](textbook-courseware-plan.md)，本轮不改变其待实施状态。

来源按服务端核验的文件哈希及实际页码关联章节，同一 PDF 重复上传仍可打开对应章节；同时提供上传和章节筛选时仍执行明确交集。媒体按发布快照的来源键筛选，更新教材草稿不会把旧视频归入新教材。页面分别显示来源案例、待审章节与媒体数量，读取失败保留材料并提示数量不可用。

## 失败判据

- 根据教材名称或客户端章节 ID 直接关联来源，造成跨教材或过期来源混入。
- 复核意见离开当前版本后仍用于自动批准新内容，或隐式改写课程与学生记录。
- 旧包、决定、修订或模型历史消失；需要重新导入才能恢复原有待审任务。
- 一个接口失败导致教材列表消失，或把未知待审数量展示为零。
- 延迟响应覆盖切换后的教材、章节、案例或意见草稿。
- 普通复核流程要求运行模型、填写 JSON 或重复批准已完成的相同对象。
