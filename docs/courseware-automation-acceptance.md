# 课件自动制作验收（2026-10-22）

本次按“减少审核与接入，正常流程尽量无感”的目标调整课件生产。此前科学教材候选工作暂缓，优先完成生产流程改造。

## 用户得到的流程

1. 选择教材范围并点击“自动生成教程”。30 页以内的短教材默认选全文，只有一个配置学科时自动带入。主题、教学要求和手动制作保留为可选项，未知材料不再要求重复勾选。
2. 系统在后台准备来源、规划、生成页面、对照原页检查并修复问题页。正常页面保留，每个问题页最多自动修复两次，模型或网络故障沿用现有有限重试。
3. 通过后自动保存为可播放教程，直接“打开授课”，不必再确认来源、大纲、逐页审核或最终发布。默认私有；课堂与公开分发继续使用所选许可和署名约束。
4. 仅未解决异常进入人工待办。关闭页面不影响后台制作；失败或取消不再一直显示处理中。失败任务可用“重试自动制作”恢复。手动编辑或审核会暂停自动处理，保留用户修改和旧发布。

详细编辑、AI 检查记录及视频/语音制作是可选入口。未展开媒体制作时不请求媒体来源，避免无关错误打断教程使用。

## 实现与兼容

复用现有来源准备、生成、AI 原页检查、单页重做与不可变发布，不新增依赖、数据表或迁移。页面完成与后继检查任务在同一事务提交；发布前重新检查租约、取消、文档版本、来源、结构、原图与分发范围。

新前端默认请求 `autoPublish=true`，接口仍默认 false，旧客户端和已有课件继续保留手动行为。自动完成使用 `system:courseware-automation` / `automated_approve`，与教师决定分开，不计入人工抽检或金标准。AI 纯文字回退不能自动完成需要核对原页的教程。

单页重做原先没有将修改原因加入生成提示，本次一并修复；自动修复现在能够收到发现的问题。原页不可读、来源问题或许可缺失不会通过取消人工按钮而被忽略。

```bash
uv run pyright
DOTTY_TEST_POSTGRES_ADMIN_URL=postgresql+psycopg://dotty_upgrade_test@127.0.0.1:59488/postgres uv run python -m tests.postgres_test_runner
uv run python ../../scripts/check_test_discipline.py
```

全量 974 项通过，使用独立 PostgreSQL 测试实例，没有复用本机业务库。自动制作验收包含正常直出、问题页修复、修复耗尽、手动修改保护、手动模式兼容、取消及 Worker 中断后恢复。后台任务补齐来源追踪字段后，定向重跑自动制作、AI 检查与原课件验收。

前端在 `apps/web` 执行：

```bash
pnpm generate:api
pnpm lint
pnpm vitest run
pnpm check:api
pnpm exec tsc --noEmit
pnpm run build
DOTTY_WEB_PORT=59487 pnpm run test:e2e
```

59 个 Vitest 文件、235 项通过，浏览器 49 项通过。新增浏览器场景覆盖后台检查时重新打开页面、自动变为可授课版本、没有审核/发布请求，以及 390 像素窄屏。保留旧手动审核、发布与响应丢失恢复场景。媒体入口改为按需展开后，再次定向重跑课件浏览器场景。

最终执行 `git diff --check` 并检查本次修改文档的本地链接。没有 Docker 配置变更，因此没有重建或停止原业务容器。全量测试已覆盖受影响代码，不额外重复调用改动选择器运行相同测试。
