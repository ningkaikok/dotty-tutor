### 本次发现并修复的断点

- 首批 OCR 只有整段文本，来源准备无法读取后续页段：改为按物理页识别和持久化，带原文件指纹和任务租约检查。
- 模型会生成看似正确、实际不存在的来源 ID：生成协议限制到本次真实来源及受控素材，服务端继续校验页码与定位关系。
- 模型建议的短课时低于合同下限：生成建议时间自动归一化，手动规划仍沿用原校验。
- 超时可能遗留原生模型子进程：超时停止该调用的进程组并回收，保留明确重试错误。
- OCR 标题、行内标签导致同一句原文误报不一致：只忽略格式标记，措辞变更仍阻断教材摘录发布。
- 发布响应不允许审核页 ID 列表，保存已成功却返回 500：修复响应契约，并在响应丢失时先恢复已持久化的发布结果。
