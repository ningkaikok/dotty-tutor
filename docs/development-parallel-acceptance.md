## 实际检查记录

测试使用本轮专用 PostgreSQL `127.0.0.1:59367`，临时运行库和目录由原测试设施创建/清理，不使用业务数据库。PDF 原页使用本机已有 Poppler；视频所需 FFmpeg 通过 `uv pip install --target output/test-native/wheels --no-deps ffmpeg-binaries==1.1.0` 独立准备（[发布包说明](https://pypi.org/project/ffmpeg-binaries/1.1.0/)），仅把其 `ffmpeg/binaries/bin` 前置测试进程 PATH，不改变系统安装或项目依赖。模型调用使用原外部 Runtime 固定实现，不调用付费服务。

首轮检查：后端完整 runner 实际执行 930 项，10 失败、4 报错、1 跳过；失败涉及 Windows 文件权限/目录同步兼容、缺少视频渲染工具、测试依赖真实模型发现及运行期间仍在修改的权限代码。前端首轮 57 文件、219 项测试通过。上述结果不作为最终通过，修复后结果更新在下方。

| 实际命令 | 最终结果 |
| --- | --- |
| `uv run ruff check .` | 通过 |
| `uv run pyright` | 0 errors、0 warnings；提示仓库根 `.venv` 不存在不影响检查退出 0 |
| `uv run python -m tests.postgres_test_runner` | 941 项执行，939 通过、2 跳过，258.6 秒；没有数据库用例因缺少测试库而跳过 |
| `python scripts/test-changed.py --base HEAD --frontend-only` | 受影响的 11 文件、52 项通过；后端因修改迁移/存储已单独执行完整 runner |
| `pnpm lint` | 通过；曾在并行保存类型文件期间遇到临时语法错误，文件冻结后重新执行退出 0 |
| `pnpm vitest run` | 58 文件、226 项通过 |
| `pnpm generate:api`、`pnpm check:api` | 已由应用 OpenAPI 生成，类型无漂移 |
| `pnpm exec tsc --noEmit`、`pnpm run build` | 通过 |
| `pnpm run test:e2e --output ../../output/final-e2e-results` | 全套 48 项通过，1.4 分钟；代码冻结后从头重跑，不拼接此前失败批次 |
| `python scripts/check_test_discipline.py`、`git diff --check` | 通过 |

后端两项跳过分别是既有 POSIX 进程组清理测试（Windows 不适用）和创建符号链接返回 `WinError 1314` 的来源预览路径逃逸测试；该安全场景需有符号链接权限的环境补跑，不算本机通过。SVG 缺少 Cairo 的结果是评测业务报告内的明确跳过，不能充作模型成功。

浏览器使用既有独立 API fixture，后端持久化/权限/原图/视频用真实临时数据库与原渲染器验证。各浏览器执行者使用独立端口及输出目录，避免 Playwright 清理同一 `test-results` 干扰其他任务。新增错误恢复、手机和跨课时场景未减弱旧用例的答案边界及翻页可见断言。

测试后已停止本轮创建的 PostgreSQL 服务。没有变更 Docker 配置，Docker 四项检查未运行；本地必跑项均已实际执行，PR CI 另行验证 Linux 环境。没有执行付费模型、真实教材导入或真人审核；缺材料/参与者的项目继续保持待验。
