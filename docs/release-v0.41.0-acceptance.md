# v0.41.0 发布验收（2026-10-24）

本次发布包括文件持久化、学生连续学习、整本教材自动续做，以及教材制作路径与样式整理。基线为 main `8818217e`，候选分支 `release/v0.41.0`。按用户最新要求，仅提交、合并与发布 GitHub 版本，不部署 Render，不同步 `deploy/render-supabase`。

## 课件流程与样式

- 教材卡片始终提供教材管理入口；已有课件可直接管理或授课，不再让旧版课程计数掩盖成果。
- 教材管理优先展示章节、已有课件和实际进度。已有成果时折叠新制作；空教材直接显示设置。只在关联章节提供唯一且已配置学科时自动带入，其他情况由用户明确选择。
- 来源页不重复展示多个页面标题；短教材选中全文、长教材推荐整本，仍需明确点击启动。普通读取与刷新不创建任务。
- 已发布章节先展示可用课件，不再继续提示制作中或要求重新审核发布；制作、异常、草稿状态分别呈现下一步。
- 上传、章节编辑、教材管理、预览、教师目录与授课共用页头底座。管理表单和卡片沿用 Bright UI，修复单选框被普通输入框样式污染及列表布局缺失。
- 授课页保留完整工具、版本信息与翻页。预览省略重复授课工具，翻页位于内容前；发布动作保持既有权限、版本和来源门禁。

流程与样式实现由两位 Luna（极高）Orca Worker 完成；Lead 独立审查、修复遗留问题并执行集成验收。未使用原业务库进行测试，没有创建真实模型任务或提交学生答案。
