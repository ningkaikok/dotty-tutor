# 课件流程与样式统一计划（2026-10-24）

## 实测问题

在真实 localhost:59174 用现有773页教材、1章7页已发布课件检查：

- 教材卡片能授课，却没有直接可见的教材管理和继续整本制作入口；目录标题与“制作互动课件”重复指向相同章节地址。
- 已发布章节仍呈现自动制作中的说明，列表显示 completed / published；主要操作与已经完成的状态不对应。
- 来源页的外层/内层重复标题与说明掩盖实际设置；高级规划、来源修订标识穿插在主路径。
- 章节工作区的选择器、课件列表和制作区缺少完整样式，实际呈现默认列表与蓝色链接；其他来源表单又使用旧蓝灰色卡片和窄小圆角。
- 上传页、教材原页编辑、教师单元目录和授课页仍有自制顶部栏，品牌/返回/标题规则不一致。

## 用户应看到的流程

| 页面 | 主要内容与下一步 |
| --- | --- |
| 我的教材 | 实际课件数量；已发布课件直接授课；始终可进入同一本教材管理并继续制作 |
| 教材管理 | 教材名称、已有课件、制作进度；开始新页段或整本制作作为清楚的操作；高级设置按需展开 |
| 新制作 | 一处标题，选择一次学科和制作范围，一次启动；长教材推荐整本，仍明确显示全书页数并需点击启动 |
| 制作中 | 真实进度、已完成课件和必要的暂停/恢复；不把正常自动检查当人工审核待办 |
| 已有课件 | 优先显示可授课课件；已发布、草稿、制作中、需处理等中文状态，不显示仍在等待制作的错误提示 |
| 预览与授课 | 统一返回和页面头部；预览、编辑、发布和授课各有明确职责；完整翻页/互动/来源依据可用 |

## 统一样式

沿用现有 Bright UI 的颜色、字体、间距与圆角变量，复用 MaterialsHeader/AppHeader、PageHeader、Button/ButtonLink、Badge/Notice/Card。所有制作管理页使用相同最大宽度与单一页面标题。播放器属于课件内容区域，外围导航和操作与其余页面统一。

清理已有规则，补齐真正缺失的布局；不以层层追加覆盖代替整理。单选框和复选框独立处理，避免普通文本输入框样式污染。桌面、768px与320px逐页核对，无横向溢出、遮挡、重叠或长标题截断。
