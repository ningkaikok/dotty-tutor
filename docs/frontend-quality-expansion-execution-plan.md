# 前端组件系统与教材质量扩展执行计划

日期：2026-10-12。工作区基线：`4ab30e98`。实现阶段保留已有 roadmap 文档改动；用户随后授权将已验收结果发布为 v0.38.0，并同步部署分支。
本轮由三个子代理实施，主代理负责契约协调、代码审查、隔离测试和浏览器验收。

## 交付目标与边界

| 批次 | 目标 | 可交付结果 | 验收边界 |
| --- | --- | --- | --- |
| A | 前端组件系统和视觉迁移 | 共享 token、布局、表单、反馈、导航/对话框组件；开发预览；现有页面接入；Bright 剩余页面按角色/用途迁移 | 组件键盘/禁用/错误状态、窄屏、真实路由回归；数学和业务状态沿用现有实现 |
| B | 恢复真实材料复核与完整单元覆盖 | 定位 18 案例和真实课件，校验源文件/哈希/环境；复核入口及可持续导入/恢复方式；覆盖缺口显式展示 | 先只读盘点；恢复不覆盖人工决定或发布历史；缺失材料明确报告；教师决定仍由真人提交 |
| C | OCR 公式质量 | 基于已记录 Badcase 的可复现输入、保留 OCR 原结果、异常检测/人工确认与回归 | 真实扫描未提供时仅运行公开教材图像页，不能宣称纸质扫描质量通过；不靠猜测自动改公式 |
| D | 区域裁图及课件媒体/语音 | 从可信来源区域生成受控素材；明确课件不可变发布到媒体/步骤语音的适配 | 坐标/来源/资产权限及学生答案隔离；缺少可信区域时回退整页，不能伪造定位 |
| E | 第三学科与人工评测 | 显式学科规则、审核门禁和真实来源约束；独立双审语料流程、盲评/配对统计门槛 | 合成案例不能计入 50+ 人工金标准；不足时无正式排名，真实教学效果待人工验收 |

## 分工与依赖

- frontend：`apps/web/` 全部前端实现与组件/E2E 测试、`.design-sync/`、`docs/design-system.md`。保留原 API 契约，新增客户端只按主代理确认的 OpenAPI 生成。
- courseware：后端课件资产、覆盖、媒体/语音发布适配与对应行为测试。负责新增领域契约；迁移编号先报主代理，避免冲突。不得修改后端复核/评测/OCR/学科 profile 文件。
- quality：后端来源复核、OCR Badcase 防误通过、第三学科 profile/模板、人工双审评测流程与测试；只读定位真实材料并在忽略目录准备恢复清单。不得修改课件资产/媒体/语音实现和共享装配/生成类型。
- 主代理：共享装配、接口协调、生成类型协调、全局架构/API/代码地图/roadmap/CHANGELOG、原材料恢复的最终执行、独立验收。不会代替教师确认教学质量。

B/C/E 与 A 可并行；D 先固定课件发布适配契约，前端随后接入。后端子代理提交共享接口约定后再编辑，避免各自维护一套来源或发布状态。

## 独立验收与失败判据

1. 子代理先写 `user` + Given/When/Then 验收场景；纯函数/组件用 Vitest/RTL，真实路由/布局用 Playwright，持久化用隔离 PostgreSQL。
2. 恢复清单记录材料路径、SHA-256、原环境、目标环境和匹配关系；不打印密钥/学生内容，不覆盖原件和原数据库，先证明备份/幂等和来源校验。
3. 非可信区域、伪造来源、未审核发布、答案泄漏、旧 Worker 回写、模型替代教师审核、合成来源计入人工金标准：相关路径验收失败。
4. OCR 改进必须保留原始文本和识别候选，区分确定性异常提示与语义校准；没有真实扫描样本不得报告真实扫描准确率。
5. 主代理实际执行 AGENTS.md 全部后端/前端门禁、测试纪律、链接/差异检查；按文件审查生成类型漂移、权限和历史兼容。
6. 验收报告分别记录工程通过、材料实际恢复、实际模型/OCR是否执行、待教师复核、未完成的 50+ 双审与排名。失败修复后复跑受影响检查。

## 执行结果

批次实现与独立验收见[验收报告](frontend-quality-expansion-acceptance.md)。材料已实际恢复为待审，工程门禁与真人教学质量分别记录。子代理初始分工后由主代理接续完成；课件代理独立审查发现撤回访问、理科配音语言、区域素材上限与在途语音来源失效问题，均已修复并验证。
