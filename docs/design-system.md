# 界面设计规范（Bright）

本文件描述前端新版视觉方向“Bright”（明快学习）的设计 token 和使用规则。目标用户以初中学生为主，
同时服务教师和内容生产者：界面要明快、有鼓励感、触控友好，但信息密度仍需支撑教师与工作室的管理场景。

token 定义在 `apps/web/src/styles.css` 顶部的 `:root` 中，命名以 `--c-`（颜色）、`--radius-`
（圆角）、`--font-` 和 `--touch-` 开头。**新样式只引用 token，不再写硬编码色值**。

## 迁移状态

迁移按页面分批进行，未迁移页面暂时保留旧的绿灰配色：

| 页面 | 状态 |
| --- | --- |
| 首页 `/` | 已迁移 |
| 学生今日 `/learn` | 已迁移（含加载骨架、出错提示、练习与已完成作业） |
| 错题本 / 拍照录入 / 确认 / 陪练 / 复习 `/mistakes/*` | 已迁移 |
| 做题 `/learn/papers/:id` | 已迁移（题目选项、填空等共享组件只在 `.student-paper-shell` 内覆盖） |
| 按需讲解（LessonPlayer）、章节学习 `/learn/chapters/:id`、课件 | 待迁移 |
| 教师工作台 `/teacher` | 待迁移（需同步更新 E2E 截图基线 `teacher-dashboard`） |
| 教材工作室 `/studio` 及子页面 | 待迁移（指标页需同步更新截图基线 `learning-cost-report`） |

已迁移页面通过 `src/styles.css` 里 `:root:has(...)` / `body:has(...)` 两个选择器切换为淡紫底；新增迁移页面时把其根容器类名加进这两个选择器。
根容器是共享类（如 `.app-shell`）时，先给页面加一个专属类名，再把覆盖样式挂在它下面，避免影响其它页面。

共享组件“为什么这样判”（`.evaluation-evidence`）的样式放在全局 `styles.css`：它同时出现在做题页和错题陪练，
两处样式表都随路由懒加载，放在任一页面的样式表里都会让另一处在首次进入时没有样式。

| 状态 | token | 说明 |
| --- | --- | --- |
| 答对 / 已掌握 | `--c-success-soft` 底 + `--c-on-success-soft` 字 | |
| 答错 / 需要修正 / 待确认 | `--c-accent-soft` 底 + `--c-on-accent-soft` 字 | 有意不用红色：对学生是“再想想”，不是惩罚 |
| 部分正确 / 中性提示 | `--c-info-soft` 底 + `--c-on-info-soft` 字 | |
| 删除 / 归档 / 请求失败 | `--c-danger`、`--c-danger-soft` | 只用于破坏性操作和系统错误 |

## 颜色

| token | 色值 | 用途 |
| --- | --- | --- |
| `--c-ink` | `#1c1442` | 正文、标题、深色按钮底 |
| `--c-ink-soft` | `#4a4370` | 次要正文、描述 |
| `--c-ink-muted` | `#5a5280` | 标签、元信息 |
| `--c-ground` | `#f1effc` | 页面底色、卡片内的标签底 |
| `--c-surface` | `#ffffff` | 卡片 |
| `--c-surface-tint` | `#f7f6fe` | 表格行、卡片内分区、悬停 |
| `--c-line` / `--c-line-strong` | `#eeeafd` / `#d9d4f5` | 分隔线、次要按钮描边 |
| `--c-brand` | `#3a2bc4` | 主色：主按钮、主视觉块、选中态 |
| `--c-brand-strong` | `#251a8f` | 主按钮悬停 |
| `--c-brand-soft` | `#eeeafd` | 选中选项底、序号底、骨架屏 |
| `--c-on-brand` | `#e4e0ff` | 紫色块上的次要文字 |
| `--c-accent` | `#ff9f1c` | 强调：提交、继续上次、焦点环；**只做底色，上面用 `--c-ink` 文字** |
| `--c-accent-soft` / `--c-on-accent-soft` | `#ffe3bd` / `#6b3a00` | 数量徽标、提醒条、“需帮助” |
| `--c-success-soft` / `--c-on-success-soft` | `#d3f5e6` / `#0b5537` | 完成、已掌握 |
| `--c-info-soft` / `--c-on-info-soft` | `#dce7ff` / `#1d3a8a` | 中性分类标签 |

对比度约束：

- 橙色 `--c-accent` 上的白字不达标，橙底一律配 `--c-ink` 文字。
- 正文最浅只用到 `--c-ink-muted`，它在白底和 `--c-ground` 上都高于 4.5:1。
- 需要区分状态时同时改变明度（例如完成用浅绿底深绿字、待办用浅橙底深棕字），不只靠色相。

## 字体

- `--font-bright`：Nunito（拉丁字母与数字，通过 `@fontsource-variable/nunito` 本地打包）+ 系统中文字体
  （PingFang SC / Microsoft YaHei / Noto Sans SC）。不加载网络中文字体，离线可用。
- 字重：正文 400–500，按钮与标签 700–800，标题 900。
- 字号：页面主标题 `clamp(28px, 4vw, 40px)`，首页主视觉 `clamp(34px, 5.5vw, 60px)`，卡片标题 16–24px，
  正文 15–16px，元信息 12–13px。题干不小于 20px。

## 圆角与间距

| token | 值 | 用途 |
| --- | --- | --- |
| `--radius-sm` | 12px | 小按钮、序号块 |
| `--radius-md` | 16px | 按钮、输入框 |
| `--radius-lg` | 24px | 卡片 |
| `--radius-xl` | 28px | 主视觉块、做题区 |
| `--radius-pill` | 999px | 导航胶囊、徽标、筛选 |

- 卡片之间 10–20px，卡片内边距 16–28px；不用阴影区分层级，靠白卡 + 淡紫底的明度差。
- 列表行（任务、错题、复习）统一为白色圆角卡片行：序号块 + 标题/描述 + 徽标 + 一个主按钮。

## 交互与可访问性

- 可点击目标最小 `--touch-min`（44px）；做题选项最小 68px 高。
- 焦点环统一为 3px `--c-accent` 描边，偏移 2–3px。
- 当前所在位置用深色胶囊（`--c-ink` 底白字），可点击但未选中的用白色胶囊。
- 首页“上次入口”只做视觉强调（紫色描边 + 橙色主按钮），不自动跳转——这是 `ProductHome` 的既有约束。
- 状态文案沿用现有组件：加载用骨架行保持高度，全部失败时不能显示“没有待办”。

## 参考原型

后续页面（错题、复习、做题、陪练、教师工作台、教材工作室）按方向 C 的交互原型迁移；原型中的班级、
题目和辅导话术是示意数据，迁移时以现有组件的数据结构和文案为准。
